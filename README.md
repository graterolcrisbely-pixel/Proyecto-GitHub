# Mi Portafolio

## Descripción

Este proyecto es una página web de presentación personal creada como
parte de mi primera entrega utilizando Git y GitHub.

El objetivo es practicar la creación de repositorios, organización de
archivos, commits y publicación de proyectos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Funcionalidades

- Página de presentación personal.
- Sección sobre mí.
- Sección de habilidades.
- Sección de contacto.
- Botón interactivo con JavaScript.
- Diseño adaptable a dispositivos móviles.

## Autor

Estudiante de desarrollo de software.

## Aprendizaje

Durante este proyecto practiqué la organización de un proyecto,
el control de versiones con Git y la publicación de código mediante GitHub.
